# Resolve
## 1. Check nguyên nhân
SQL> 
```
set lines 200;
col name format a30;
col cause format a30;
col message format a100;
col status format a10;
SELECT name, cause, message, status FROM pdb_plug_in_violations WHERE status <> 'RESOLVED'; 
```
## 2. Fix
SQL>
```
SET LINESIZE 200;
SET PAGESIZE 100;
ALTER SESSION SET NLS_DATE_FORMAT = 'DD-MM-YYYY HH24:MI:SS';
ALTER SESSION SET NLS_TIMESTAMP_FORMAT = 'DD-MM-YYYY HH24:MI:SS.FF';

COL ctime FORMAT A25;
COL name FORMAT A20;
COL sqlstmt FORMAT A80;
SELECT ctime, name, sqlstmt FROM PDB_SYNC$ WHERE sqlstmt LIKE '%KBTT%';
```

```
DELETE FROM PDB_SYNC$ WHERE sqlstmt LIKE '%KBTT%';
commit;
```

SQL>
```
ALTER SESSION SET CONTAINER = CDB$ROOT;
ALTER PLUGGABLE DATABASE KBTT_STAGING_PDB CLOSE IMMEDIATE;
```
