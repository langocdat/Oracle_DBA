# Required
- The target oracle home version same to source oracle home
- The target os same to source os

# Step 1: Copy ra_wallet from source database to target database
*Mục tiêu: Sao chép thư mục ra_wallet sang máy chủ cần khôi phục*
```
[oracle]$ cd $ORACLE_HOME/bin
[oracle]$ tar -cvzf ra_wallet.tar.gz ra_wallet
[oracle]$ scp ra_wallet.tar.gz oracle@68.68.xxx.xxx:$ORACLE_HOME/dbs
```

# Step 2: Create the configuration ZDLRA file in target database
*Chú ý: Thay đổi giá trị ZDLRA_$DB_NAME phù hợp*
```
[oracle]$ cd $ORACLE_HOME/dbs/
[oracle]$ vi ra$ORACLE_SID.ora
RA_WALLET='location=file:/u01/app/oracle/product/19.3.0/db_1/dbs/ra_wallet credential_alias= ZDLRA_$DB_NAME'
```

# Step 3: Add alias in tnsnames.ora file on target database
*Chú ý: Thay đổi giá trị ZDLRA_$DB_NAME phù hợp*
```
[oracle]$ cd $ORACLE_HOME/network/admin
[oracle]$ vi tnsnames.ora
ZDLRA_$DB_NAME  =
  (DESCRIPTION =
    (ADDRESS_LIST =
      (ADDRESS = (PROTOCOL = TCP)(HOST =68.68.xxx.xxx)(PORT = 15xx))
    )
    (CONNECT_DATA =
      (SERVICE_NAME = db1db1)
    )
  )
```
