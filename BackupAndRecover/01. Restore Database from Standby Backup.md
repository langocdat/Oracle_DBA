## 3.8 Restore datafile
```
run {
allocate channel d1 device type disk;
allocate channel d2 device type disk;
allocate channel d3 device type disk;
allocate channel d4 device type disk;
allocate channel d5 device type disk;
allocate channel d6 device type disk;
SET NEWNAME FOR DATABASE TO '+DATA'; 
SET NEWNAME FOR tempfile 1 TO '+DATA';
restore database;
switch datafile all;
switch tempfile all;
}
```

## 3.9 Recover database
```
run {
allocate channel d1 device type disk;
allocate channel d2 device type disk;
allocate channel d3 device type disk;
allocate channel d4 device type disk;
allocate channel d5 device type disk;
RECOVER DATABASE;
}
```

## 3.10 Activate Standby database to Primary database 
*__Because it is the backup from Standby database, so we need active standby database to Primary database__*

SQL> ```alter database activate physical standby database;```

SQL> ```alter database open;```
